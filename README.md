# 📚 Book catalogue (React frontend)

React + Vite frontend for the Book API. Lists, searches, sorts, adds, edits and deletes books.

## Run locally

```bash
npm install
npm run dev
```

Opens at http://localhost:5173. The backend URL is set in `.env`:

```
VITE_API_URL=http://localhost:8080
```

## Build

```bash
npm run build
```

The production files are created in `dist/`.
